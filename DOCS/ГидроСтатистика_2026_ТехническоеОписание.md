## 3. Ключевые алгоритмы

### 3.1. Пирсон III типа (СП 33 п.6.4)

Плотность вероятности:

```
f(x) = (1/(α^β × Γ(β))) × (x−ε)^(β−1) × exp(−(x−ε)/α)
```

где:
- α = Cs²/4 — параметр формы
- β = 4/Cs² — параметр масштаба
- ε = Qср − 2×Cv×Qср/Cs — параметр положения

Квантили вычисляются через обратную функцию Гамма scipy:

```python
Q(P) = ε + α × gamma.ppf(1 - P, β)
```

### 3.2. Cornish-Fisher (аппроксимация)

```
x(P) = z(P) + (1/6)×(z²−1)×Cs + (1/24)×(z³−3z)×(Cs²−3×(Ku−3)) − (1/36)×(2z³−5z)×Cs³
```

где z(P) — квантиль нормального распределения, Ku — эксцесс.

### 3.3. Поправка на автокорреляцию (СП 33 п.6.2.4)

```
Cv_испр = Cv × √((1 + r₁) / (1 - r₁ × (n-2)/(n-1)))
```

где r₁ — коэффициент автокорреляции первого порядка.

### 3.4. Тест Диксона (выбросы)

```
Q_крит = |x_{i+1} - x_i| / (x_{max} - x_{min})
```

Сравнивается с табличным значением для n наблюдений и уровня значимости α=0.05.

### 3.5. Метод Риппла (многолетнее регулирование)

```
V_необ = max[ Σ_{i=1}^{k} (Q_i - Q_забор) ] для всех k = 1..n
```

Минимальный объём водохранилища, при котором забор Q_забор гарантирован на 100% времени.

### 3.6. Кривая подпора (метод последовательных сечений)

```
Δx = (E₂ - E₁) / (I - S̄_f)

где:
E = h + V²/(2g) — энергетический напор
S_f = Q²n²/(ω²R^(4/3)) — уклон трения (Маннинг)
```

### 3.7. Степень таяния снега (СП 33 п.8.1)

```
M_i = A × T_air,i × Δt (при T_air > 0)

где A — коэффициент таяния (2.0–4.0 мм/сут при +10°С)
```

### 3.8. Метод рациона (СП 33 п.8.3)

```
Q = q × F × α / 3.6

IDF: i = A × T^m / (t + B)^n
```

### 3.9. Сезонный Тессман (СП 32 прил. 8)

```
Q_эк_i = α_i × Q_ср × (Q_i / Q_ср)^β_i

где:
α_i — доля экостока от среднего расхода для месяца i
β_i — параметр чувствительности (0.5–1.0)
```

### 3.10. Экспонента Хёрста (R/S анализ)

```
H = lim_{n→∞} log(R_n / S_n) / log(n)

H > 0.5 — persistentный (долгосрочная память)
H = 0.5 — случайное блуждание
H < 0.5 — антипersistentный
```

## 6. Точность и ограничения

| Параметр | Точность | Ограничение |
|----------|----------|-------------|
| Qср | ±0.1% | Требуется n ≥ 15 (СП 482) |
| Cv | ±5–15% | Зависит от n и формы ряда |
| Cs | ±20–40% | Ненадёжно при n < 20 |
| ε | ±1–10% | Рекомендуется ε < 10% |
| IDF | Региональная | Аппроксимация для 9 зон |
| ГВП | ±5–10% | Зависит от грубости сечений |
