## 1. Цель baseline

Зафиксировать единую нормативную карту проекта в виде прослеживаемой цепочки

```
нормативный документ → пункт / формула / таблица / требование
→ расчётная методика → реализация HydroSphere → тест → статус соответствия
```

и отделить **доказанное** соответствие от **заявленного**. Baseline не является
оценкой качества программы и не заменяет первоисточники: он фиксирует, что
известно, что не известно и что опровергнуто.

**Почему `VERIFIED` только 18,6 %.** Это не оценка качества кода. `VERIFIED`
требует одновременно: наличие первоисточника, точной привязки к формуле,
реализации и теста, который проверяет **именно это требование**. Проект
сильно документирован, но большинство требований либо не реализовано (15),
либо первоисточник не получен (23), либо реализована только часть (44).

**Найдено сверх существующей матрицы** (проверкой полных текстов СП 33):

- **Ложная ссылка в гидравлике.** `core/hydraulics.py:37` и
  `core/profile.py:172` ссылаются на **п. 7.4** («раздельно считаем русло и
  поймы»). П. 7.4 — про однородность параметров и усреднение по
  рекам-аналогам. **Правильный пункт — п. 7.68.** Требование при этом
  реализовано верно, неверно только цитирование.
- **СП 33 содержит формулу расхода (7.49)** — Q = ω·h^(2/3)·I^(1/2)/n,
  где **n — коэффициент шероховатости в с/м^0,33**. Термины «Маннинг» и
  «Чези» в стандарте **не встречаются** (0 совпадений на 85 страницах).
  Размерность n в коде не проверена.
- **Таблица 7.3** (4 значения: 0,02 / 0,05 / 0,17 / 0,40) — нормативное
  основание для распределения расхода между руслом и поймой, **не
  используется** в коде.
- **Единицы модуля стока:** СП 33 использует **оба** обозначения — м³/с·км²
  (п. 4.15, формулы (7.15), (7.21)) и **л/с·км²** (п. 7.67). A.8-контракт
  работает с л/с·км². Множитель 1000 не зафиксирован как требование.

## 5. Наиболее критичные GAP

1. **GAP-01 — Базовый документ не выбран, и он уже не один.** СП 529.1325800.2023
   **действует** (подтверждено на protect.gost.ru). СП 33-101-2003 действующего
   статуса на текущую дату **не подтвердить**: в каталоге Росстандарта он
   отсутствует, в тексте СП 529 он не упоминается, а карточка СП 529 поле
   «заменяемый документ» пусто. Связь между документами — `UNKNOWN`.
   **Хуже, чем «выбрать один»:** в двух документах **п. 4.7 означает разное**
   (СП 33 — однородность; СП 529 — вероятности превышения), и **буквы приложений
   переназначены** (Б: «таблицы значений параметров расчётных формул» в СП 33 →
   «аналитические кривые распределения» в СП 529; таблицы параметров переехали в В).
   До решения нельзя корректно поставить ни одну ссылку проекта.
2. **GAP-02 — Первоисточник номограмм `[4]` отсутствует** (Рождественский,
   1977, 269 с.). Без него **метод приближённого МП по п. 5.5 нереализуем**:
   переход λ₂, λ₃ → C_v, C_s в самом СП 33 отсутствует.
3. **GAP-03 — Первичные ряды аналогов (МДС) отсутствуют.** 23 значения за
   1986–1992 нет в наличии; для golden-верификации нужно 276 значений по
   пяти аналогам.
4. **GAP-04 — Единицы не закреплены ни одним тестом.** П. 4.15 СП 33 даёт
   нормативный перечень (Q м³/с, W м³, q м³/с·км², h мм, H см), но ни одна
   граница % ↔ доля, ни одно преобразование площади/слоя/модуля не
   проверяется. Риск ошибки множителя 100.
5. **GAP-05 — Формула (5.44) не реализована, хотя полностью доступна.**
   Гарантийная поправка ΔQ₀,₀₁% = α·E₀,₀₁%·Q₀,₀₁%/√N извлекается из
   локального PDF дословно вместе с тремя ограничениями (α по условию 5.1,
   ≤ 20 %, «не меньше наблюдённого») и таблицей Б.6 (135 значений уже
   перенесена). Блокера нет — есть недоработка.
6. **GAP-06 — Отдельный конфликт C_s/C_v = 0 в КМ.** Расхождение до 3,6e-3
   из-за guard `abs(cs) < 0.001 → cs = 0.001`. Зафиксировано, не исправлено.
7. **GAP-07 — Пять нормативных таблиц не имеют потребителя.** Б.6, Б.7, Б.10,
   7.4, 7.5 перенесены или найдены, но формулы, которые ими пользуются, не
   реализованы. Это самый дешёвый путь к росту `VERIFIED`.
8. **GAP-08 — Внутреннее противоречие проекта по формуле (7.51).** Журнал
   утверждает «реализована и сверена», реестр утверждает «НЕ реализована».
9. **GAP-09 — Гидравлика без первоисточников.** Критическая/нормальная
   глубина, rating curve, коэффициент шероховатости — `SOURCE_MISSING`.
10. **GAP-10 — Два файла в `DOCS/` имеют ложные имена.** `Рождественский.pdf`
    — это Ленгидметинститут, 1964; `Пособие по определению…характеристик.pdf`
    — это сб. науч. трудов 1989. Вывод по имени файла был бы неверен.
11. **GAP-11 — Ложная ссылка в гидравлике.** `core/hydraulics.py:37`,
    `core/profile.py:172`: п. 7.4 вместо **п. 7.68**. Требование реализовано
    верно, неверен номер пункта.
12. **GAP-12 — Размерность коэффициента шероховатости не проверена.** СП 33
    задаёт n в **с/м^0,33**, а не безразмерный коэффициент Маннинга.
    Соответствие кода не установлено.
13. **GAP-13 — Порог достаточности ряда расходится с действующим стандартом.**
    СП 529 п. 5.1.1 допускает относительную среднюю квадратическую погрешность
    **10 % для годового и сезонного** и **20 % для максимального и минимального**
    стока. Код предупреждает по единому порогу 10 %, нормированному на C_s/C_v.
    Для максимального и минимального стока код тем самым **блокирует расчёт,
    который стандарт разрешает**. Конфликт зафиксирован в
    `tests/test_sp33_km_coefficient_policy.py`.
14. **GAP-14 — Новое требование СП 529 п. 4.1 о сравнительной оценке погрешностей
    не выполнено ни для одной методики.** Для 10 «инженерных» методик реестра
    требуется сравнение погрешностей с методами стандарта. Требования не было в
    СП 33.
15. **GAP-15 — Письмо Исх-7095 «О наличии опечаток в СП 529.1325800.2023» не
    получено.** Оно блокирует любую численную golden-сверку по СП 529:
    неизвестно, какие значения признаны опечатками. Запросить первым.
16. **GAP-16 — Печатный оригинал СП 529 (118 с.) не получен.** Текст доступен,
    но **тела формул утрачены** и структура таблиц Приложения Б рассыпана.
    Ни одна формула не проверена по знакам и коэффициентам; нули таблицы Б.1 и
    один хвостовой узел не верифицированы по действующему стандарту.
17. **GAP-17 — Доверительные интервалы нормативны (5.1.12–5.1.13, таблица В.3).**
    Ранее их отсутствие мотивировалось тем, что «в СП 33 нет раздела 8.5».
    В СП 529 требование существует явно, довод неприменим, таблица В.3 не
    транскрибирована.
18. **GAP-18 — Сетка обеспеченностей уже нормы.** Таблица Б.1 СП 529 содержит
    **40** уровней P, проект — **27**. Уровни 2…9, 0,06…0,09, 99,8, 99,95,
    99,98, 99,99 отсутствуют и восполняются интерполяцией, причём код не
    различает табличное и интерполированное значение.
