## 0. Как читать этот документ

Этот документ — **не** пересказ уже существующего
`DOCS/normative_verification_matrix.md` (1270 строк, журнал проверок 2026-09-25…29).
Существующий файл остаётся **источником фактов**; здесь эти факты приведены к
единой схеме со статусами и дополнены инвентаризацией, которой там не было
(единицы, граничные условия, таблицы, отчётность, реестр документов).

### 0.1 Статус требования

| Статус | Значение | Условие присвоения |
|---|---|---|
| `VERIFIED` | Соответствие доказано | Есть первоисточник, точная привязка к формуле/пункту, и тест, проверяющий именно это требование |
| `PARTIAL` | Соответствует часть | Пункт/формула реализованы не полностью, либо реализована одна из ветвей |
| `CONFLICT` | Расхождение доказано | Код даёт результат, отличный от первоисточника, и расхождение зафиксировано |
| `NOT_IMPLEMENTED` | Требование есть, реализации нет | Пункт/формула в стандарте существуют, кода нет |
| `SOURCE_MISSING` | Первоисточник не установлен | Формула реализована, но нормативного источника получить не удалось |
| `LEGACY` | Исторический документ | Документ заменён/отменён; релевантен для воспроизведения старых расчётов |
| `REFERENCE` | Вспомогательный источник | Официальный, но не нормативный документ; либо вторичный источник-указатель |
| `OUT_OF_SCOPE` | Вне области | Реализовано, но стандарт такое применение не описывает |
| `UNKNOWN` | Недостаточно данных | Доказательств недостаточно; домысливание запрещено |

### 0.2 Статус документа

`CURRENT` — действующий. `LEGACY` — заменён/отменён, но нужен для
воспроизведения. `REFERENCE` — официальный не-нормативный либо вторичный.
`UNKNOWN` — статус подтвердить не удалось.

### 0.3 Правила, которые здесь соблюдались

1. **Наличие файла в `DOCS/` не означает нормативность.** Каждый локальный
   документ открыт и прочитан; выводы — из содержимого, не из имени файла.
   Два файла в `DOCS/` имеют **ложные имена** (см. §9).
2. **Код работает ≠ соответствует норме.** `VERIFIED` требует привязки к
   конкретному пункту/формуле первоисточника.
3. **Существующий тест ≠ доказательство.** Тест считается доказательством
   только если проверяет конкретное нормативное требование.
4. **Формула не считается верной потому, что математически корректна.**
5. **Формулировки вида «примерно соответствует» не используются.**
6. Ссылка на пункт СП 33 проверялась машинно по
   `tests/fixtures/sp33_clause_index_v1.json` (168 пунктов, разделы 1–7;
   **раздела 8 не существует**).
