# ГидроСтатистика 2026 — Техническое описание и руководство пользователя

---

## 1. Общее описание

**«ГидроСтатистика 2026»** — программный комплекс для гидрологических расчётов по строительным нормам Российской Федерации.

Приложение предназначено для:
- Проектирования гидротехнических сооружений (плотины, водохранилища, водосбросы)
- Определения расчётных гидрологических параметров (Qср, Cv, Cs, ε)
- Построения кривых обеспеченности
- Расчёта минимального и максимального стока
- Оценки экологического стока
- Расчёта ледовых явлений
- Водного баланса бассейна
- Инженерных изысканий

### Нормативная база

| Стандарт | Содержание |
|----------|-----------|
| **СП 33-101-2003** | Определение основных гидрологических параметров |
| **СП 482.1325800.2020** | Инженерные изыскания для строительства |
| **СП 58.13330.2019** | Водохранилища, каналы и водоёмы |
| **СП 32.13330.2018** | Канализация. Наружные сети и сооружения |
| **РД 52-26-2008** | Гидрометеорологические прогнозы |
| **СП 219.1325800.2020** | Системы водоотведения |

## 4. Формат входных данных

### Формат Excel (рекомендуемый)

Файл `.xlsx` должен содержать:
- Столбец `year` — год наблюдений
- Столбец `value` — расход (м³/с) или уровень (м)
- Столбец `post` — название поста (если несколько)

### Единый шаблон

Меню **«Файл данных → Загрузить единый шаблон»** — загружает файл с несколькими постами в одном файле.

### Ручной ввод

Кнопка **«Ввести данные вручную»** на вкладке «Данные»:
- Ввод значений через запятую или по одному на строку
- Режим: «Только значения» или «Год + Значение»
- Поддержка копирования из буфера обмена

## 5. Руководство по вкладкам

---

### 5.1. Данные и статистика

**Назначение:** Загрузка данных, базовая статистика, кривые обеспеченности.

**Действия:**
1. Загрузить файл (меню «Файл данных») или ввести вручную
2. Выбрать пост из выпадающего списка
3. Нажать **«Рассчитать параметры»** — появятся Qср, Cv, Cs, ε
4. Выбрать тип кривой (Пирсон III, Крицкий-Менкель, нормальное)
5. Нажать **«Построить кривую»** — график и таблица

**Дополнительные кнопки:**
- **Однородность** — тест Диксона и Граббса на выбросы
- **Тренды** — анализ Манна-Кендалла, Сен's slope, Pettitt
- **Сохранить график** — экспорт в PNG/JPG/PDF

---

### 5.2. Норма годового стока (Работа 1)

**Назначение:** Расчёт среднегодового модуля стока, оценка достоверности.

**Алгоритм:**
1. Загрузить годовые средние расходы
2. Рассчитать Qср = ΣQ/n
3. Вычислить Cv = σ/Qср (с поправкой на автокорреляцию)
4. Вычислить Cs (коэффициент асимметрии)
5. Оценить ε = Cv/√n

**Результаты:**
- Qср (м³/с), модуль стока (л/с·км²), объём (км³/год)
- Cv, Cs, ε
- График ряда с линией тренда

---

### 5.3. Внутригодовое распределение (Работа 2)

**Назначение:** Анализ суточного и месячного хода стока.

**Возможности:**
- Месячные расходы и их отклонения
- Годовой гидрограф
- Типичный год (модельный)
- Распределение стока по месяцам

---

### 5.4. Минимальный сток (Работа 3)

**Назначение:** Расчёт минимальных расходов для экологии и водоснабжения.

**Методы:**
- Минимум за 7 суток (7Q)
- Минимум за 10 суток (10Q)
- Минимум за 30 суток (30Q)
- 7Q10 — 7-суточный минимум с обеспечённостью 10% (СП 32)
- Сравнение методов

---

### 5.5. Максимальный сток (Работа 4)

**Назначение:** Расчёт паводковых расходов.

**Вкладки:**
1. **Расчёт максимумов** — извлечение годовых максимумов, кривая Пирсона III
2. **Кривая Q=f(H)** — рейтинг-кривая (гидравлическая зависимость)
3. **Индексные годы** — метод для рек без наблюдений

**Ввод данных:**
- Загрузка суточных данных (автоматически извлекает максимумы)
- Ручной ввод максимальных расходов

---

### 5.6. Ледовые явления (Работа 5)

**Назначение:** Расчёт параметров ледового режима.

**Возможности:**
- Выбор климатической зоны (6 зон РФ)
- Толщина льда (формула СП 33 + статистика)
- Заторный паводок (метод Саварена)
- Высота подъёма воды при заторе
- Длительность ледостава

**Формулы:**
- Толщина: `δ = A × √|T_янв|`
- Заторный подъём: `ΔH = k × (b/L)^0.5`

---

### 5.7. Водный баланс (Работа 6)

**Назначение:** Баланс осадков, испарения и стока.

**Расчёты:**
- Баланс: `W = P − E ± ΔS`
- Испарение по Дальтону: `E = (a + b×W) × (e_s − e_a)`
- Испарение по Мещерскому: `E = E_оз × (1 + k×ΔT)`
- Коэффициент стока: `α = R/P`
- Коэффициент водного баланса: `β = R/P`

---

### 5.8. Метод рациона + IDF + Гидрографы (Работа 7)

**Назначение:** Расчёт паводков для малых бассейнов (<50 км²).

**Вкладки:**

#### Метод рациона + IDF
- `Q = q × F × α / 3.6`
- 9 климатических зон РФ
- IDF-кривые: `i = A × T^m / (t + B)^n`
- Автопроверка применимости (F < 50 км², t > 5 мин)

**Пример:** F=25 км², T=10 лет, t=60 мин, α=0.70 → Q = ?

#### Паводочный гидрограф
- **Гамма** (СП 33): `Q(t) = Q_пик × (t/T_нар)^α × exp(α(1−t/T_нар))`
- **Треугольный** асимметричный
- Объём паводка: `W = ∫Q(t)dt`

#### Снеготаяние
- Градусно-суточный метод: `M = A × T_air` (мм/сутки)
- 9 климатических зон
- Запас воды в снеге: `W = H × ρ / 1000`

---

### 5.9. FDC + Регрессии + Статистика (Работа 8)

**Назначение:** Кривая длительностей и расчёты для нелогометрических рек.

#### Кривая длительностей (FDC)
- Показывает % времени, когда Q ≥ заданного
- Перцентили: Q10, Q50, Q90
- Показатель формы n (устойчивость режима)
- Отношение Q90/Q10 (характеристика межени)

#### Регрессии (9 бассейнов)
- `Q_ср = A × F^n`
- Бассейны: Волга, Обь-Иртыш, Енисей, Лена, Кама, Дон, Нева, Кавказ, Центральная Россия

#### Продвинутая статистика
- **MLE** — оценка параметров максимальным правдоподобием
- **L-моменты** — робастная оценка параметров
- **Сравнение распределений:** Пирсон III, Log-Пирсон III, GEV, Вейбулл-3, Гамма, Нормальное
- **Q-Q / P-P графики** — диагностика качества подбора
- **AIC / BIC** — критерии выбора лучшего распределения

---

### 5.10. ППУ + ГВП + Регулирование (Работа 9)

**Назначение:** Гидротехнические расчёты плотин и водохранилищ.

#### Пропускная способность ППУ
- **Свободный перелив:** `Q = C_d × L × H^1.5`
- **Лотковый водосброс:** C_d = 1.50–2.20 (по типу)
- **Шахтный водосброс:** `Q = C_d × A × √(2gH)`
- Проверка: пропускает/не пропускает расчётный паводок

#### Кривые подпора (ГВП)
- Метод последовательных сечений: `dx = (E₂−E₁)/(I−S̄_f)`
- Нормальная глубина (Маннинг): `Q = (1/n)×ω×R^(2/3)×√I`
- Расстояние подпора от водохранилища

#### Многолетнее регулирование
- Метод Риппла: `V = max Σ(Q_i − Q_забор)`
- Кривая «объём — обеспечение водоснабжения»
- Месячный баланс стока

---

### 5.11. Экология + Базовый сток (Работа 10)

**Назначение:** Экологический сток, фильтрация, спектральный анализ, засухи.

#### Экологический сток
- **Сезонный Тессман:** `Q_эк_i = α_i × Q_ср × (Q_i/Q_ср)^β_i`
- 4 типа регионов: северные, центральные, южные, горные
- Классы экорежима I–VI
- Метод мокрого периметра

#### Базовый сток
- Прямолинейное разделение
- Цифровой фильтр Boughton: `q_b(t) = α×q_b(t−1) + (1−α)×Q(t)`
- Фильтр Лайна-Холлика
- Доля базового стока (%)

#### Спектральный анализ
- **FFT** — выявление периодичности
- **Энергетический спектр** — мощность по частотам
- **Экспонента Хёрста (H):**
  - H > 0.5 — persistentный (есть долгосрочная память)
  - H = 0.5 — случайное блуждание
  - H < 0.5 — антипersistentный

#### Индексы засухи
- **SPI** — стандартный индекс осадков
- **SPEI** — индекс осадков минус испарение
- Классификация WMO: от «Рекордная засуха» до «Экстремально влажно»

## 6. Дополнительные инструменты (панель кривой)

На вкладке «Кривая обеспеченности» доступны:

- **Кривая с точками ГТС** — автоматическая подстановка расчётных обеспеченностей по классу сооружения (I–IV)
- **Составная кривая (авто)** — поиск неоднородности (Pettitt), тест Манн-Уитни, построение составной кривой
- **Удлинить ряд по аналогу** — валидация корреляции (R > Ro), регрессионный/пропорциональный метод

## 8. Краткая справка по формулам

### Статистические параметры (СП 33 п.6.2)

| Параметр | Формула | Описание |
|----------|---------|----------|
| Qср | `ΣQ_i / n` | Средний расход |
| Cv | `σ / Qср` | Коэффициент вариации |
| Cs | `Σ(Q_i−Qср)³ / (n×σ³)` | Коэффициент асимметрии |
| ε | `Cv / √n × 100%` | Относительная ошибка |
| K_r | `1 + 0.33×r₁` | Поправка на автокорреляцию |

### Пирсон III (СП 33 п.6.4)

`Q(P) = Qср × (1 + Cv × (K_p − 1))`

где K_p — квантиль Пирсона III для обеспечённости P

### Метод рациона (СП 33 п.8.3)

`Q = q × F × α / 3.6`

| Параметр | Ед. | Описание |
|----------|-----|----------|
| Q | м³/с | Расход паводка |
| q | мм/ч | Интенсивность дождя |
| F | км² | Площадь бассейна |
| α | — | Коэффициент стока (0.3–0.95) |

### Градусно-суточный метод (СП 33 п.8.1)

`M = A × T_air` (мм/сутки)

| Зона | A (мм/сут при +10°С) |
|------|---------------------|
| Арктика | 2.5 |
| Центральная | 3.5 |
| Юг | 4.0 |
| Кавказ | 3.5 |
| Вост. Сибирь | 2.8 |

## 9. Известные ограничения

1. IDF-кривые аппроксимированы для 9 основных климатических зон
2. Регрессионные уравнения适用于区域性ных рек (не для горных ручьёв)
3. Метод Риппла для многолетнего регулирования использует упрощённую модель
4. Спектральный анализ требует минимум 20 лет данных
5. Экспонента Хёрста рекомендуется при n > 50
