# HydroSphere

## Описание проекта

Гидрологический анализовый инструмент для инженеров-гидрологов. Помогает оценивать режимные характеристики сточных вод: статистические параметры ряда, кривые обеспеченности, проверку однородности, анализ трендов, расчёт максимального/минимального стока и многолетнее регулирование.

## Цели проекта

- Создание комплексного инструмента для гидростатистического анализа
- Обеспечение соответствия СП 33-101-2003 и другим нормативным документам
- Возможность работы с ежегодными и суточными рядами расхода
- Поддержка распределения Пирсона III и метода Крицкого-Менкеля для кривых обеспеченности

## Заинтересованные стороны

- Инженеры-гидрологи
- Научные сотрудники
- Руководители проектов
