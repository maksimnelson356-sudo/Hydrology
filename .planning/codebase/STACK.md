# Технологический стек

## Языки
- Python 3.10+ (основной язык реализации)

## Среда выполнения и фреймворки
- PyQt6 >= 6.6 (GUI-фреймворк)
- Стандартная библиотека Python (дополнительных крупных фреймворков нет)

## Зависимости
- numpy >= 1.26 (численные вычисления)
- scipy >= 1.11 (научные вычисления)
- pandas >= 2.1 (манипулирование данными)
- matplotlib >= 3.8 (построение графиков/визуализация)
- openpyxl >= 3.1 (работа с Excel-файлами)
- requests >= 2.31 (HTTP-запросы)
- pytest >= 8.0 (тестовый фреймворк)
- pyinstaller >= 6.0 (создание исполняемых файлов)

## Инструменты разработки
- pyright (проверка типов)
- ruff (линтинг/форматирование)
- black (форматирование кода)
- isort (сортировка импортов)

## Конфигурация
- pyproject.toml (конфигурация инструментов: pyright, ruff, isort, black)
- requirements.txt (зависимости для запуска)
- .gitignore (шаблоны для игнорирования в git)

## Сборка и распространение
- PyInstaller для создания автономных исполняемых файлов
- build.py, build_installer.py, build_nuitka.py, build_visualization.py (скрипты сборки)
- create_template.py, create_test_data.py (вспомогательные скрипты)
- tools/run_methodology.py (консольный запуск методик)
