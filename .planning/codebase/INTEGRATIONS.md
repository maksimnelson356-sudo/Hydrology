# Внешние интеграции

## Форматы файлов
- Excel (.xlsx, .xls) через openpyxl
- JSON (.hsp) формат проекта для персистентности
- Простые текстовые отчёты (различные .txt выводы)

## Внешние сервисы и API
- Не обнаружено (в кодовой базе нет вызовов HTTP API)
- Вся обработка выполняется локально с использованием научных библиотек

## Интеграция с базами данных
- Нет интеграции с базами данных (используются структуры данных в памяти и персистентность через файлы)
- Данные проекта хранятся в файлах .hsp в формате JSON
- Отсутствуют ORM или соединители с базами данных

## Интеграция с оборудованием
- Прямая интеграция с оборудованием отсутствует
- Предназначено для работы с данными, экспортированными из измерительных устройств (формат Excel)

## Библиотеки и научные методы
- Стек SciPy для статистических вычислений:
  - scipy.stats для подгонки распределений и статистических тестов
  - numpy для численных операций
  - pandas для обработки данных и обработки CSV/Excel
- matplotlib для построения графиков и визуализации
- PyQt6 для настольного GUI

## Поток данных
1. Ввод: Файлы Excel или ручной ввод данных через GUI
2. Обработка: Научные вычисления с использованием numpy/scipy
3. Хранение: Состояние проекта сохраняется в виде файлов .hsp в формате JSON
4. Вывод: Отчёты, графики и экспорт данных

## Точки интеграции
- GUI интегрируется с сервисами расчётов через сигналы/слоты PyQt6
- Сервисы расчётов предоставляют API для использования GUI
- Модульный дизайн позволяет использовать сервисы независимо (консольный запуск)
- Потоки worker обрабатывают длительные расчёты, чтобы не блокировать GUI
