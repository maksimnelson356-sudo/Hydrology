# HydroSphere

Приборная панель для гидростатистики. Нормативная база — СП 33-101-2003 и
смежные своды правил, но **соответствие этим стандартам подтверждено не для
всех расчётов**: одна методика сверена с печатным первоисточником полностью,
часть — частично, остальные помечены как инженерные. Точный перечень по
методикам — в разделе «Сводный перечень нормативного статуса» файла
`DOCS/normative_verification_matrix.md`. Ниже кратко.

## Что это

Гидрологический анализовый инструмент для инженеров-гидрологов. Помогает оценивать режимные характеристики сточных вод: статистические параметры ряда, кривые обеспеченности, проверку однородности, анализ трендов, расчёт максимального/минимального стока и многолетнее регулирование.

Обрабатывает ежегодные и суточные ряды расхода, использует распределение Пирсона III и метод Крицкого-Менкеля для кривых обеспеченности.

## Запуск

### Требования

- Python 3.10+
- Зависимости: numpy, scipy, pandas, PyQt6

Установить зависимости:

```bash
pip install numpy scipy pandas PyQt6
```

### GUI

```bash
python gui/main_window.py
```

Или (если есть venv):

```bash
.venv\Scripts\python.exe gui/main_window.py
```

### Консольный прогон методов

```bash
# Список зарегистрированных методик
python tools/run_methodology.py --list

# Расчёт одной методики на демо-данных
python tools/run_methodology.py --method stats_parameters --demo

# Свой файл данных: год обязателен
python tools/run_methodology.py --method frequency_pearson3 --file path/to/data.xlsx --post "Пост 1"
```

Требования к файлу `--file` (`.xlsx` / `.xls`): в рабочем листе должен быть
**год** — отдельной колонкой «год»/«year» либо в первой колонке. Без года
чтение прерывается, а не подставляет годы по порядку: иначе статистика
считалась бы по мусору. Титульные строки над заголовком допускаются, как в
книгах МДС. `--post` задаёт имя листа; без него берётся первый лист.

### Тесты

```bash
python -m pytest tests -q
```

Ожидаемый результат: **797 passed** в `tests/` (полный набор — 932).

## Методики P0

В реестре зарегистрировано **24 методики** (9 P0 + 15 расширенных). Колонка
«Статус» показывает, что именно подтверждено сверкой с первоисточником:
`источник` — сверено, `частично` — сверена часть, `инженерный` — нормативной
привязки нет, `не подтверждён` — источник отсутствует или опровергнут.

## Примечания

- Навигация: **23 раздела** (Проект, Методики, Данные и статистика, …, Отчёт, …)
- Методики не запускают ядро напрямую, а делегируют в него через CalculationService и сериализуют результаты для .hsp
- Валидаторы применимости проверяют длину ряда и обязательные параметры перед запуском
- Принцип «не изменять данные молча»: сервисы только оценивают данные, реальное исправление делает пользователь
- Сборка: `python build.py pyinstaller` → `dist/HydroSphere/HydroSphere.exe`
