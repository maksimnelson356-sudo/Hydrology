## 1. ОБЩАЯ ХАРАКТЕРИСТИКА ПРОЕКТА

Проект представляет собой специализированное ПО для гидрологических расчетов, включающее:

### 1.1 Основные модули:
- **Гидравлические расчеты** (`core/hydraulics.py`) - расчет расходов воды по формуле Маннинга
- **Морфометрия русла** (`core/profile.py`) - обработка поперечных профилей с разделением на русло и пойму
- **Статистический анализ** (`core/stats/`) - комплексный анализ гидрологических рядов
- **Графический интерфейс** (`gui/main_window.py`) - интерфейс для работы с данными

### 1.2 Функциональность статистического модуля:
- Расчет статистических параметров с поправками на автокорреляцию
- Построение кривых обеспеченности (Пирсона III, Крицкого-Менкеля, нормальное распределение)
- Анализ трендов (линейный тренд, тест Манна-Кендалла, наклон Сена, тест Петтитта)
- Проверка однородности (критерии Граббса и Диксона)
- Восстановление пропущенных данных методом регрессии

def kritsky_menkel_ppf(probabilities, mean, cv, cs):
    if abs(cs) < 0.05:
        shape = 4.0 / (cv ** 2)
    else:
        shape = max(0.8, (2.0 / cs) ** 2)
    scale = mean / shape
    quantiles = stats.gamma.ppf(probabilities, a=shape, scale=scale)
```

def calculate_q_manning(omega, chi, n, i, cos_alpha=1.0):
    R = omega / chi  # Гидравлический радиус
    q = (1.0 / n) * omega * (R ** (2.0 / 3.0)) * math.sqrt(i) * cos_alpha
```

✅ **Учитываемые параметры:**
- Площадь живого сечения (ω)
- Смоченный периметр (χ)
- Коэффициент шероховатости (n)
- Уклон (i)
- Угол наклона русла (cos α)
